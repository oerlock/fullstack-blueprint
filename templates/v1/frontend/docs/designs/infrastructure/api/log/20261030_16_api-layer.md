# 20261030_16 api-layer

## 主题

按 `../../../../../README.md`「后端 API」一节落地基于 OpenAPI 快照的 API 生成层，参考
`slash_pixel` 项目的实现。

## 变更

- 新增 `frontend/orval.config.ts`、`frontend/devops/sync-openapi.mjs`。
- 新增 `frontend/src/api/`：`error.ts`、`request.ts`、`query-client.ts`。
- `package.json` 新增 `api:sync` / `api:generate` / `api:update` / `api:check` 脚本。
- 首次同步后端 OpenAPI 快照并生成 `frontend/src/api/generated/`。
- `main.tsx` 挂载 `QueryClientProvider`。

## 与参考实现的差异

- 后端无鉴权，`request.ts` 不含 access token provider。
- 错误体解析适配本项目后端约定 `{code, message, metadata}`。
- 全局错误提示使用 sonner（参考项目为 i18n + 内部 notify 模块）。
