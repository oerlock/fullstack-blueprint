# 全栈模板

前后端一体的全栈项目模板：FastAPI 后台 + React 前端。

## 目录

- `backend/`：FastAPI 后台，详见 [backend/README.md](backend/README.md)
- `frontend/`：React 前端，详见 [frontend/README.md](frontend/README.md)
- `docs/`：全局项目文档与规范
- `devops/`：开发辅助脚本

## 快速开始

1. 克隆项目到本地。
2. 为本项目配置专属的 Git 用户名和邮箱：

   ```sh
   git config --local user.name "你的用户名"
   git config --local user.email "你的邮箱"
   ```
